# ADR-004: Deterministic Multi-Machine Simulator with Scenario Seeds

## Context

Early development, continuous integration, and client demonstrations lack permanent physical connections to 10 industrial injection molding machine PLCs. A simulator is required to model production execution, downtime events, and operator response realistically.

## Decision

Build an in-process, deterministic **Multi-Machine Simulator** governing 10 virtual injection molding machines with scenario seed support, configurable speed multipliers, fault injection, mold changeovers, and disconnect simulations.

### Baseline Scenario Configuration

- **Initial Default Condition:** Steady-state normal operating flow.
- **Machine Allocation:**
  - **8 Machines (`IMM-01` to `IMM-08`):** Cycling in normal steady-state flow (demonstrating standard output and expected cycle times).
  - **1 Machine (`IMM-09`):** Triggerable slow-cycle scenario (cycle time expands by 40-60%, demonstrating OEE Performance loss).
  - **1 Machine (`IMM-10`):** Triggerable fault scenario (hydraulic pressure alarm trips the machine, demonstrating OEE Availability loss and automated Andon dispatch).
- **Interactive Workflow:** Operators can raise Digital Andon tickets, and technicians can acknowledge, diagnose, and resolve tickets.
- **Reproducibility:** All scenarios can be reset to baseline and replayed with 100% deterministic reproducibility using a scenario seed.

## Consequences

- **Positive:** Guarantees that OEE algorithms, fault containment, and real-time dashboard latency can be thoroughly verified and demonstrated without hardware dependencies.
- **Negative:** Telemetry generated by the simulator must be explicitly marked with `isSimulated: true` to prevent confusion with physical machine telemetry.
