# Lessons

- Saat menulis atau menyusun dokumentasi proyek (PRD, SDD, spesifikasi teknis, ADR), selalu gunakan bahasa Inggris sebagai bahasa kanonis dokumentasi sistem kecuali jika pengguna secara eksplisit meminta bahasa lain.
- Always adhere strictly to `DESIGN.md` light theme specifications (`surface: #FFFFFF` page canvas). Prohibit dark canvas backgrounds (`bg-slate-950`). Use Atlassian semantic lozenges with visible 1px borders, sentence case for all UI copy (buttons, table headers, labels, lozenges), and never substitute un-tokenized neon gradient palettes for canonical Atlassian design tokens.
- Dilarang keras mengada-ada atau menanam data mock/hardcoded (dummy data) di frontend hanya demi mencocokkan tampilan visual dengan referensi gambar tanpa integrasi data nyata. Jika sistem belum memiliki endpoint atau struktur data pendukung, jelaskan batasannya secara transparan kepada pengguna dan bangun endpoint backend yang murni menghitung data riil dari database/telemetri, atau tawarkan visualisasi alternatif yang sepenuhnya kompatibel dengan data sistem yang ada.
